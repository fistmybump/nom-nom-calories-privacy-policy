# Nom Nom Calories — Privacy Policy

This repository hosts the privacy policy for the **Nom Nom Calories** Android app, served via GitHub Pages.

## Live URL

- GitHub Pages: https://fistmybump.github.io/nom-nom-calories-privacy-policy/
- Custom domain (if DNS is configured): https://nomnomcalories.com/

## Structure

- `index.html` — the privacy policy page
- `CNAME` — custom domain configuration for GitHub Pages

## Updating the Policy

Edit `index.html` and push to `main`. GitHub Pages will automatically redeploy.
